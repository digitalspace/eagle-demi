What happens next

Access control
Chunks copy read[] from the live document, so an ingest can never widen visibility.
Chunking
Deterministic ids of the form <documentId>::p<page>::c<index>, so the route is idempotent and an interrupted backfill restarts.
Indexing
Search indexers pull from Cosmos every five minutes; nothing is pushed. Deletes are removed from the index explicitly.
Projects
Never created from an ingest. A row whose upstream id resolves to no project is dropped and counted.

Before you mint one

Ask for the least privilege that works
A key minted with demi-service-read reads everything the ACL allows and writes nothing. Write access is a separate role, and no key can reach /api/admin/*.
Project scope is orthogonal to privilege
A scoped key is privileged within those projects. Scope arrives as roles prefixed project: and narrows the partition, so privilege lifts the role predicate but never the project one.
The secret is shown once
Format is demi_<env>_<keyId>_<secret>, sent as X-Api-Key. DEMI stores a hash, so a lost key is rotated, not recovered.
Rotate before revoking
Mint the replacement, deploy it, then revoke the old one — revocation takes effect immediately and is recorded in the audit log.

Never commit a key literal. This repository is public, so a literal in it is a world-readable credential; ADMIN_API_KEY is break-glass only.
