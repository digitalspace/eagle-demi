What happens next

Access control
Chunks copy read[] from the live document, so an ingest can never widen visibility.
Chunking
Deterministic ids of the form <documentId>::p<page>::c<index>, so the route is idempotent and an interrupted backfill restarts.
Indexing
Search indexers pull from Cosmos every five minutes; nothing is pushed. Deletes are removed from the index explicitly.
Projects
Never created from an ingest. A row whose upstream id resolves to no project is dropped and counted.

Writes require demi-service-write or a staff role. Every ingest is audited.
